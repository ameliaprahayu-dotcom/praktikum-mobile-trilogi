## Teknologi
- Kotlin, Jetpack Compose (Material 3)
- Android Studio Quail 4 (2026.1.4), Min SDK 24

## Cara Menjalankan
1. `git clone https://github.com/ameliaprahayu-dotcom/praktikum-mobile-trilogi.git`
2. Buka folder hasil clone di Android Studio, tunggu **Gradle Sync** selesai.
3. Pilih emulator / perangkat, lalu klik **Run**.
